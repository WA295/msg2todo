# ☁️ 云服务器部署指南

把 msg2todo 部署到云服务器后,手机 App **在任何网络(4G/5G/学校 WiFi)都能用**,彻底摆脱"和电脑同网"的限制。

## 一、买服务器(5 分钟)

任选一家(都有学生优惠,9.9 元/月左右):

- 阿里云:轻量应用服务器 / ECS 学生机
- 腾讯云:轻量应用服务器 / 学生机
- 京东云 / 华为云:同样有活动价

配置要求:**2 核 2G 足够**(跑 NapCat + msg2todo)。系统选 **Ubuntu 22.04 或 24.04**。

拿到的东西:公网 IP + root 密码(控制台可重置)。

## 二、一键部署(2 分钟)

SSH 登录服务器后运行:

```bash
curl -sL https://raw.githubusercontent.com/WA295/msg2todo/master/scripts/deploy-cloud.sh -o deploy-cloud.sh
# 国内服务器 GitHub 不通时用:
# curl -sL https://ghfast.top/https://raw.githubusercontent.com/WA295/msg2todo/master/scripts/deploy-cloud.sh -o deploy-cloud.sh
bash deploy-cloud.sh
```

常用环境变量:

```bash
# 设置访问密码 + 天气城市 + 用国内镜像加速
TOKEN=你的密码 WEATHER_CITY=沈阳 MIRROR=1 bash deploy-cloud.sh
```

部署完成会输出看板地址 `http://<IP>:8080`。

## 三、装 QQ 机器人(可选但推荐)

在服务器上按 README「QQ 接入(OneBot v11)」章节安装 NapCat:

```bash
curl -sL -o napcat.zip 'https://ghfast.top/https://github.com/NapNeko/NapCatQQ/releases/download/v4.18.30/NapCat.Shell.zip'
# 之后照 README 步骤:复制 QQ 目录 → 解压 napcat → 写 loadNapCat.js → 改 package.json
```

无头启动(服务器没有图形界面):

```bash
DISPLAY= /opt/QQ-napcat/qq --no-sandbox --disable-gpu --ozone-platform=headless -q <你的QQ号>
```

首次启动控制台会打印二维码,扫码登录(建议用 QQ 小号)。登录成功后配置反向 WS 指向 `ws://127.0.0.1:3001`(云端 OneBot 只监听本机,安全)。

建议做成 systemd 服务开机自启(参考本机 `~/.config/systemd/user/napcat.service`,云上用系统级 `/etc/systemd/system/`)。

## 四、迁移本地数据

```bash
# 本地电脑执行(把课表/待办传到云上):
scp ~/msg2todo/data/todos.db root@<服务器IP>:/opt/msg2todo/data/
```

上传后重启云端服务:`systemctl restart msg2todo`。

## 五、重新打包手机 App(内置云地址)

在本地电脑执行:

```bash
cd ~/msg2todo && git pull
SERVER=http://<服务器IP>:8080 TOKEN=<访问密码> bash scripts/build-apk.sh
```

- `dist/msg2todo-安卓.apk` 即成品,**发给同学装完打开即用**
- 手机浏览器也可直接访问 `http://<服务器IP>:8080`(输入访问密码)
- iPhone 同样用 Safari 打开 → 添加到主屏幕

## 安全建议

- 务必设置 `WEB_AUTH_TOKEN`(部署脚本 TOKEN 参数),否则数据对公网裸奔
- 云端 OneBot 监听 `127.0.0.1`,不暴露 QQ 接口
- 云服务器控制台安全组只需放行 8080 端口(若用 HTTPS 再放 443)

## 常见问题

| 问题 | 解决 |
|------|------|
| 手机打不开看板 | 确认安全组放行 8080;`systemctl status msg2todo` 看服务状态 |
| QQ 机器人连不上 | 云端 NapCat 反向 WS 填 `ws://127.0.0.1:3001`;查看日志是否有「登录成功」 |
| 想用 HTTPS | 反代方案:域名 + Caddy/Nginx 自动证书(后续可加) |
