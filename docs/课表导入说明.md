# 📚 课表导入说明

iTodo 支持 **多种格式导入课表**,并对所有已导入数据自动识别 **星期 / 节次 / 周次 / 教室 / 单双周**。

三种方式任选:

| 方式 | 怎么做 | 适用 |
|------|--------|------|
| 📄 文件 | 在 App「📚 课表」页上传,或把文件发给机器人 | 教务系统能导出 Excel/CSV |
| 🖼 图片 | 上传课表截图 / 拍照 | 只能截图,没有文件 |
| ⌨️ 文字 | 直接发课程行给机器人(见下) | 手工录入少量课程 |

---

## 一、文件导入(xlsx / xls / csv)

支持两类常见导出格式,**无论哪种都能自动识别**:

### 1. 网格课表(课表格子)

表头是星期,左侧一列是节次或时间,格子里是课程信息。

- **表头**:`星期一` / `周一` / `周一` / `Mon` / 数字 `1` 均可;表头在第几行不限(自动查找),允许上方有标题行
- **节次列**:`第一节`(按 90 分钟大节)、`第1节`、`1-2节`、`08:00-09:40` 都可以
- **格子内容**:通常多行,如
  ```
  高等数学
  1-16周
  浑南校区 计算机101
  ```
  第一行识别为课程名,含"周"的行识别为周次,含"楼/室/区/教室/机房"等识别为地点

### 2. 课程列表(每行一节课)

一行一节课,按下述表头关键字自动对应列(列名可有出入):

| 列 | 可识别表头 |
|----|-----------|
| 课程 | 课程名称 / 课程名 / 课程 / 名称 / 教学班 |
| 星期 | 星期 / 周几 / 上课星期 / 星期几 |
| 节次(或时间) | 节次 / 节数 / 上课时间 / 时间 / 节 |
| 周次 | 周次 / 周数 / 上课周 / 起止周 |
| 地点 | 上课地点 / 地点 / 教室 / 场地 |

---

## 二、周次 / 单双周写法

以下都能识别:

```
1-16周        1,3,5周       1-16(单周)      第1-16周
单周          双周          1-16周(单)      1,3,5,7,9
```

- 单周 → `odd`,双周 → `even`
- 没写周次 → 默认「每周都上」

## 三、图片识别(截图 / 拍照)

在 App「📚 课表」页上传图片,或把课表截图发给机器人,系统用**视觉大模型**识别成课表。

### 启用条件(管理员一次性配置)

在 `.env` 里填:

```bash
LLM_API_KEY=你的密钥
LLM_VISION_MODEL=qwen-vl-max      # 需支持图片输入;也可 glm-4v / gpt-4o 等
# LLM_BASE_URL 用对应厂商的 OpenAI 兼容地址
```

> 留空 `LLM_VISION_MODEL` 时会退用 `LLM_MODEL`;**若该模型不支持看图则会失败并提示**。

### 识别失败怎么办?(重要兜底)

不配置视觉模型、或图片不清晰时,用 **「豆包」等 AI 识图 → 转文字**:

1. 把课表图片发给「豆包」(或其他支持识图的 AI),让它按行念出课程;
2. 把识别出的文字整理成课程行,**直接粘贴发给 iTodo 机器人**:

   ```
   课表
   周一 08:00-09:40 高等数学 @一教101
   周二 10:00-11:40 大学英语 1-16周
   周三 14:00-15:40 物理实验 双周
   ```

即可导入。提示:图片越清晰(能看清"星期"和"节次")识别越准。

## 四、文字导入(指令)

| 指令 | 说明 |
|------|------|
| `课表` + 课程行 | 整体覆盖课表(可多行) |
| `添加课` + 课程行 | 追加,不清空已有 |
| `我的课表` | 查看自己的课表 |
| `明天什么课` / `今天什么课` | 立即查询 |
| `开学日期 2026-02-23` | 设置开学日期(决定第几周,用于单双周/周次) |
| `清空课表` | 删除全部课程 |
| `课表帮助` | 查看完整说明 |

课程行格式:`周X HH:MM-HH:MM 课程名 @地点 [周次] [单/双周]`

## 五、常见问题

| 问题 | 说明 |
|------|------|
| 文件解析不出课程 | 确认是教务系统导出的课表;也支持 `.csv`;实在不行用文字方式 |
| 图片识别失败/不准 | 换更清晰的截图;或配置视觉模型;或用「豆包识图 → 粘贴文字」 |
| 单双周不对 | 发 `开学日期 YYYY-MM-DD`(所在周为第 1 周) |
| 导入后没有每晚提醒 | 每晚 `SCHEDULE_NOTIFY_TIME`(默认 21:00)自动私聊提醒次日课程;可发 `提醒时间 21:30` 单独设置 |
| 网页端上传入口 | 「📚 课表」页 → 导入课表(文件 / 图片) |

## 六、技术说明

- 解析逻辑:`src/excelImport.js`(`tryGrid` 网格 / `tryList` 列表 / `periodRange` 节次),
  图片识别:`src/llm.js` 的 `extractScheduleFromImage`
- 上传统一入口:`parseScheduleUpload()` —— 按文件头判断「图片 → 视觉识别 / 表格 → 解析」
- 节次→时刻默认内置东北大学时刻表,其他学校可扩展 `excelImport.js` 里的 `PERIOD_START`
